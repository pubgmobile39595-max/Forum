# 📢 Forum

Modern özellikli forum uygulaması. Node.js + Express + SQLite.

## ✨ Özellikler

- 🔐 Kullanıcı sistemi (kayıt, giriş, roller, puan)
- 📝 Konu açma, yorum, Markdown, anket
- 💬 Özel mesaj, arkadaşlık, takip
- 👑 Admin panel, moderasyon, spam filtresi
- 🎨 Karanlık/açık tema, mobil uyumlu

## 🚀 Kurulum

    git clone https://github.com/pubgmobile39595-max/Forum.git
    cd Forum
    npm install
    node server.js

Tarayıcıda: http://localhost:3000

## 🛠️ Teknolojiler

- Node.js, Express
- SQLite3
- EJS
- bcryptjs, express-session
- Multer, marked
